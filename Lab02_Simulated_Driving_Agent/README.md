# Lab 02 — Simulated Driving Agent Behavior

## 🎯 Objective

Build a **self-driving agent** simulation using **Genetic Algorithms** in Python. The agent learns to navigate a grid-based road environment by evolving its behavior over multiple generations.

---

## 📊 Dataset

- **No external dataset required** — the environment and agent behavior are simulated programmatically.
- A grid world is generated where the agent must navigate from start to finish while avoiding obstacles.

---

## 🔧 Dependencies

```
numpy, matplotlib
```

---

## ▶️ How to Run

```bash
cd Lab02_Simulated_Driving_Agent
python driving_agent.py
```

---

## 📤 Expected Output

1. **Grid World Visualization** — Display of the road environment with obstacles
2. **Genetic Algorithm Progress** — Fitness scores across generations
3. **Best Agent Path** — Visualization of the best evolved agent's path
4. **Fitness Convergence Plot** — Graph showing improvement over generations

---

## 📝 Key Concepts

- Genetic Algorithms (Selection, Crossover, Mutation)
- Agent-based Simulation
- Fitness Function Design
- Evolutionary Optimization
