# Lab 04 — Vehicle Price Prediction

## 🎯 Objective

Build **Decision Tree** and **Random Forest** regression models to predict vehicle prices from structured automotive data. Compare model performance and understand feature engineering for price prediction.

---

## 📊 Dataset

- **Synthetic vehicle dataset** generated programmatically
- Simulates a used car marketplace with features like brand, age, mileage, engine specs
- Features: Brand, Age, Mileage, Engine_CC, Horsepower, Fuel_Type, Transmission, Owner_Count
- Target: Price (in Lakhs)

No manual download required.

---

## 🔧 Dependencies

```
numpy, pandas, matplotlib, seaborn, scikit-learn
```

---

## ▶️ How to Run

```bash
cd Lab04_Vehicle_Price_Prediction
python vehicle_price_prediction.py
```

---

## 📤 Expected Output

1. **Dataset Overview** — Shape, statistics, feature distributions
2. **Decision Tree Model** — Training, evaluation, tree depth analysis
3. **Random Forest Model** — Training with multiple estimators
4. **Model Comparison** — Side-by-side MAE, RMSE, R² comparison
5. **Feature Importance** — Bar chart of most predictive features
6. **Prediction Plots** — Actual vs Predicted scatter for both models

---

## 📝 Key Concepts

- Decision Tree Regression
- Random Forest Ensemble Method
- Feature Engineering
- Model Comparison (MAE, RMSE, R²)
- Feature Importance Analysis
