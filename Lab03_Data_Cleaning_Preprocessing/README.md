# Lab 03 — Data Cleaning & Preprocessing Techniques

## 🎯 Objective

Master essential **data preprocessing techniques** — handling missing values, detecting and treating outliers, feature scaling, and encoding categorical variables — using a simulated automotive dataset.

---

## 📊 Dataset

- **Synthetic automotive dataset** generated programmatically
- Simulates real-world messy data with missing values, outliers, and mixed data types
- Features: Mileage, Engine Size, Horsepower, Weight, Fuel Type, Transmission, Price

No manual download required.

---

## 🔧 Dependencies

```
numpy, pandas, matplotlib, seaborn, scikit-learn
```

---

## ▶️ How to Run

```bash
cd Lab03_Data_Cleaning_Preprocessing
python data_cleaning.py
```

---

## 📤 Expected Output

1. **Raw Data Overview** — Shape, types, missing values summary
2. **Missing Value Handling** — Imputation using mean/median/mode strategies
3. **Outlier Detection** — Box plots and IQR-based outlier removal
4. **Feature Scaling** — StandardScaler and MinMaxScaler comparison
5. **Encoding** — One-Hot and Label encoding of categorical features
6. **Before/After Visualizations** — Distribution comparisons

---

## 📝 Key Concepts

- Handling Missing Data (Mean, Median, Mode Imputation)
- Outlier Detection (IQR Method, Z-Score)
- Feature Scaling (Standardization, Normalization)
- Categorical Encoding (One-Hot, Label Encoding)
- Exploratory Data Analysis
